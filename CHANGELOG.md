# Changelog

## 1.0.0 (2026-09-10)

First public release.

- Availability tab: free-slot lists from all enabled calendars, buffers, travel detection, time-zone conversion, German/English output, inserted at the cursor.
- Invitation tab: attendees from To/Cc and the whole thread, free-text time entry, free-slot suggestions, Google Meet through Google Calendar's editor, direct creation for server-scheduled CalDAV calendars, Thunderbird's event dialog for everything else.
- Web calendar docked beside the compose window, optionally automatic.
